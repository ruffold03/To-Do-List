# Планёрка — список задач

Минималистичный планер на чистом HTML, CSS и JavaScript. Без сборки и зависимостей.

## Возможности

- ✅ Добавление, отметка и удаление задач
- 💾 Сохранение в `localStorage` — задачи не пропадают после обновления страницы
- 📅 Календарь на месяц: задачи по дням, навигация, индикаторы выполнения
- 🗓️ Планирование на будущие даты (дата в форме или выбор дня в календаре)
- ✏️ Inline-редактирование по двойному клику (Enter — сохранить, Escape — отменить)
- ↕️ Drag & Drop с анимацией: карточка «поднимается» и следует за курсором, соседи плавно раздвигаются, а на месте остаётся пунктирный слот. Мышью — за любую часть карточки, на touch — за ручку
- 📊 Прогресс дня: полоса заполнения, «3 из 7 выполнено» и процент
- 📈 Статистика за неделю или месяц: проценты, карточки, диаграмма по дням, серия
- 🔎 Фильтры «Все / Активные / Выполненные» и очистка выполненных за день
- 📱 Полная адаптивность

## Управление

| Действие | Как |
|---|---|
| Добавить задачу | Ввести текст и нажать Enter или «Добавить» |
| Выбрать дату | Клик по дню в календаре или поле даты в форме |
| Отметить выполненной | Клик по чекбоксу |
| Редактировать | Двойной клик по тексту (или Enter/F2 на фокусе) |
| Изменить порядок | Мышью — потянуть карточку, на touch — за ручку слева |
| Удалить | Кнопка с корзиной справа |
| Статистика | Вкладка «Статистика» вверху |

## Данные

Задачи хранятся в `localStorage` под ключом `todo-tasks-v1` в виде массива:

```json
[{ "id": "…", "text": "Купить продукты", "completed": false, "date": "2026-11-08" }]
```

При первом запуске новой версии старые задачи без поля `date` автоматически переносятся на сегодня. Поле `title` из возможных старых данных также поддерживается.

## Запуск локально

Откройте `index.html` в браузере или запустите простой сервер:

```bash
npx serve .
```

git branch -M main

## Деплой на Vercel

1. Зайдите на [vercel.com](https://vercel.com) и нажмите **Add New → Project**.
2. Импортируйте репозиторий `ruffold03/To-Do-List`.
3. Framework Preset: **Other**. Build Command и Output Directory оставьте пустыми.
4. Нажмите **Deploy** — сайт будет доступен по адресу вида `to-do-list.vercel.app`.

Через CLI:

```bash
npm i -g vercel
vercel
```
